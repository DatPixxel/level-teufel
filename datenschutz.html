Datenschutzerklärung 😈

Level Teufel (Web-Version und Android-App)

Kurzfassung: Dieses Spiel erhebt, sammelt, speichert und teilt keinerlei personenbezogene Daten. Es gibt keine Werbung, kein Tracking, keine Analyse-Dienste, keine Konten und keine Server, an die etwas gesendet wird.

1. Welche Daten werden verarbeitet?

Keine. Das Spiel läuft vollständig lokal in deinem Browser bzw. auf deinem Gerät. Es werden keine Daten an den Entwickler oder an Dritte übertragen.

2. Lokaler Spielstand

Dein Spielfortschritt (freigeschaltete Level, Todeszähler, Ton-Einstellung) wird ausschließlich lokal auf deinem Gerät gespeichert (Browser-localStorage). Diese Daten verlassen dein Gerät nicht und können jederzeit über die Funktion „Fortschritt löschen" im Spiel oder durch Löschen der Browserdaten entfernt werden.

3. Hosting

Die Web-Version wird über GitHub Pages (GitHub, Inc.) ausgeliefert. Beim Aufruf der Seite verarbeitet GitHub technisch notwendige Verbindungsdaten (z. B. IP-Adresse) zur Bereitstellung der Seite. Details: GitHub Privacy Statement. Der Entwickler hat auf diese Daten keinen Zugriff.

4. Berechtigungen (Android-App)

Die App benötigt lediglich Internetzugriff zum Laden der Spielinhalte. Es werden keine weiteren Berechtigungen angefordert.

5. Kinder

Da keinerlei Daten erhoben werden, gilt dies gleichermaßen für alle Altersgruppen.

6. Kontakt

Fragen zum Datenschutz: über das Kontaktformular auf GitHub (Issues) an den Entwickler DatPixxel.
